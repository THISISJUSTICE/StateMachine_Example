\# Unity Editor Tool Previews



\## StateFlowDrawer

State 간 전환 및 Event Trigger 관계를 시각화하여  복잡한 게임 진행 흐름을 한눈에 확인할 수 있도록 제작한 Editor Tool입니다.

!\[StateFlowDrawer](./Assets/Previews/Editor/StateFlowDrawer%20Preview.png)



\---



\## API Data Editor

서버 API와 연동하여 데이터를 조회·수정할 수 있도록 제작한 Editor Tool입니다.

수동 JSON 편집 대신 Editor에서 데이터를 확인하고 수정할 수 있도록 구성했으며, 주요 Key 및 데이터 보호 기능을 통해 수정 과정에서의 오류를 방지하도록 구성했습니다.

!\[API Data Editor](./Assets/Previews/Editor/ApiDataEditor%20Preview.png)



\---



\## LocalizationMaker

Google Sheets 기반의 현지화 데이터를 파싱하고, 배포용 파일 생성부터 AWS Upload까지의 과정을 자동화한 Editor Tool입니다.

!\[LocalizationMaker](./Assets/Previews/Editor/LocalizationMaker%20Preview.png)
